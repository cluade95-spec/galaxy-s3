# LineageOS 14.1 for Samsung GT-I8200 (goldenvess3g) — feasibility project

Investigating whether Android 7.1.2 (LineageOS 14.1) can be brought to the Samsung Galaxy S III Mini Value Edition, **GT-I8200** (`goldenvess3g`, Marvell PXA986/PXA988, Vivante GC1000).

Not to be confused with GT-I8200N (`goldenve3g`) or GT-I8190 (`golden`, different chip).

**Status:** Milestone 1, research only. Nothing has been built, and nothing has been tested on hardware.
